# TechNexus.AI - Digital Assistant Platform for Teachers

TechNexus.AI is a comprehensive web-based digital assistant platform that revolutionizes how educators manage their work. The system provides AI-powered tools, a complete academic management suite, and intuitive interfaces inspired by leading EdTech products like Google Classroom, Notion, and Canva for Education.

## 🚀 Features

### 🧭 Teacher Dashboard
- Overview of current courses, students, schedules, and notifications
- AI summaries of recent class progress and student engagement trends
- Quick-access widgets for upcoming exams, assignment status, and attendance overview

### 📘 Syllabus Management
- Create, edit, and share syllabi for each course
- AI-assisted syllabus generator with auto-suggested topics, time allocations, and outcomes
- Version control and collaborative editing with co-teachers

### 🗓️ Study Schedules & Lesson Planning
- Interactive calendar with drag-and-drop lesson blocks
- AI auto-scheduler to balance workloads, holidays, and exam dates
- Option to sync with Google Calendar or MS Outlook

### 📝 Assignments & Assessments
- Create, distribute, and grade assignments online
- AI grading assistant for essays and quizzes
- Plagiarism detection and feedback suggestion tools
- Student submission portal

### 🧪 Exams & Quizzes
- Customizable exam builder with multiple question formats
- Auto-marking system with analytics (average score, difficulty index)
- Timed online exams with integrity checks

### 🤖 AI Tools Integration
- **Lesson Generator**: Create lesson plans or presentations from syllabus topics
- **Feedback Assistant**: Suggest personalized student feedback
- **Performance Analyzer**: Detect learning gaps using student data
- **Content Rewriter**: Convert teacher notes into engaging student materials
- **Quiz Generator**: Automatically create assessments from course content
- **Student Insights**: AI-powered behavior and learning pattern analysis

### 📊 Monitoring & Analytics
- Track student and teacher activity (login frequency, completion rates, engagement time)
- Dashboard for performance metrics and insights
- Notifications for inactivity or missed deadlines
- AI-generated reports for administrators or parents

## 🎨 Design Philosophy

The platform features a modern, minimalistic, and responsive design with:
- Soft gradients and rounded corners (2xl)
- Dynamic cards and modular dashboard layout
- Calm academic color palette (navy, light beige, mint, and sky blue)
- Smooth hover animations and transitions
- Fully functional and clickable interface elements

## 🛠️ Technology Stack

- **Frontend**: Next.js 14 with React 18
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion for smooth transitions
- **Icons**: Lucide React for consistent iconography
- **Calendar**: React Calendar for scheduling features
- **Charts**: Recharts for analytics visualization
- **Drag & Drop**: React DnD for interactive scheduling

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd technexus-ai
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
